## Problem and intended outcome

There is no implemented passage-based comprehension quest matching the proposed product promise. Build one reviewed instructional unit before increasing catalog size.

## Implementation scope

1. Select one skill and prerequisite band from the approved brief; author an original/licensed short passage, meaningful purpose, child prompt, expected response evidence, and common misconceptions.
2. Provide explicit modeling and optional vocabulary/read-aloud support, then require the child to explain or select evidence in a way aligned with the skill.
3. Author fresh parallel tasks with different passages for independent checks and specify allowable accommodations versus instructional help.
4. Include adult facilitation notes, printable companion, accessible text/media alternatives, and an instructional review record.

## Acceptance criteria

- **Given** a child completes the guided task, **when** they receive the independent task, **then** the passage is fresh and hints do not reveal the answer.

- **Given** a reviewer inspects each question, **when** the rubric is applied, **then** the evidence needed for a successful response is explicit and reproducible.

## Validation and evidence

Two-reviewer content walkthrough, age/reading-demand review, rights checks, accessibility review, and synthetic response examples covering misconceptions. Pilot responses are future evidence.

## Rollout, migration, and recovery

Keep content draft until approved; corrections create a new version. One quest is a prototype, not a complete paid curriculum.
